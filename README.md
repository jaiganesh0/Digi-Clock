# Digital Clock Application

A clean, responsive, real-time Digital Clock web application built with **HTML5**, **CSS3**, and **Vanilla JavaScript** as a Virtual Internship project.

## Features

- **Real-Time Clock:** Displays live hours, minutes, and seconds with tabular numerals to prevent digit jitter.
- **12-Hour & 24-Hour Switching:** Seamless toggle between 12-hour (`AM`/`PM`) and 24-hour formats.
- **Current Date & Day:** Automatically displays the full weekday name and formatted calendar date.
- **Start / Pause Control:** Pause the live display at any moment and resume synced with the current system time.
- **Built-In Alarm:** Set an alarm using the native time picker with visual alerts and Web Audio API sound notifications (zero external audio files required).
- **Preference Persistence:** Remembers your selected time format and alarm inlocalStorage`.
- **Responsive Design:** Adapts cleanly across mobile phones, tablets, and desktop screens.
